# 🪨 📄 ✂️ Pierre - Feuille - Ciseaux (Rock Paper Scissors)

Ce projet est une implémentation en JavaScript du jeu classique **Pierre-Feuille-Ciseaux**, exécuté dans la console du navigateur. Il a été réalisé dans le cadre du parcours **The Odin Project** (Foundations).

## 📝 Description

Le jeu oppose un joueur humain à l'ordinateur. Une partie complète se déroule en **5 manches** :
1. Le joueur saisit son choix (`rock`, `paper` ou `scissors`) via une boîte de dialogue (`prompt`).
2. L'ordinateur génère un choix aléatoire.
3. Le score est mis à jour après chaque manche.
4. Le résultat final et le vainqueur de la partie sont affichés à la fin des 5 tours.

## 🚀 Fonctionnalités

- **Choix aléatoire** : Génération du coup de l'ordinateur avec `Math.random()`.
- **Insensibilité à la casse** : Prise en compte de la saisie quelle que soit la casse (ex. `rock`, `ROCK`, `RocK`).
- **Suivi des scores** : Comtage automatique des points de l'humain et de l'ordinateur.
- **Partie en 5 manches** : Gestion complète du déroulement de la partie via la fonction `playGame()`.

## 🛠️ Technologies utilisées

- **HTML5** : Structure minimale pour charger le script.
- **JavaScript (ES6+)** : Logique du jeu et interactions.
- **Git & GitHub** : Gestion de version et hébergement du code.
